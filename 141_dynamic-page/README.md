# Furnish Furniture Template

Furniture and decor website template with Bootstrap, Magnific Popup and animations.

**Category:** Websites & Landing Pages  
**Tech:** HTML, CSS, JavaScript, Bootstrap, jQuery, Animate.css, LineIcons, Magnific Popup

## How to run

No build step or install needed. Open `index.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "141_dynamic-page"
python3 -m http.server 8000
```

then visit http://localhost:8000/index.html.
