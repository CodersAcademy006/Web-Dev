# Text to Speech Converter

Convert typed text to speech with pause and resume, using the Web Speech API.

**Category:** Tools & Apps  
**Tech:** HTML, JavaScript, CSS

## How to run

No build step or install needed. Open `Text to Speech Converter/index.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "106_Word Convertor"
python3 -m http.server 8000
```

then visit http://localhost:8000/Text%20to%20Speech%20Converter/index.html.
