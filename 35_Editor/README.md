# Image Editor

Easy image editor: adjust brightness, saturation, inversion and grayscale, rotate and flip, then save the edited image.

**Category:** Tools & Apps  
**Tech:** HTML, JavaScript, CSS, Font Awesome, Boxicons

## How to run

No build step or install needed. Open `Image Editor JavaScript/index.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "35_Editor"
python3 -m http.server 8000
```

then visit http://localhost:8000/Image%20Editor%20JavaScript/index.html.

## Files

```
Image Editor JavaScript/index.html
Image Editor JavaScript/script.js
Image Editor JavaScript/style.css
```

Plus 1 asset file (images, audio, fonts, etc.).
