# Luxe Hotel Template

Free responsive HTML5 hotel template by FREEHTML5.co: hotel listings, services, blog and contact pages.

**Category:** Websites & Landing Pages  
**Tech:** HTML, CSS, JavaScript, SCSS, Bootstrap, jQuery

## How to run

No build step or install needed. Open `luxe/index.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "42_Hotel Website"
python3 -m http.server 8000
```

then visit http://localhost:8000/luxe/index.html.
