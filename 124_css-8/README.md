# Padding in CSS

Explainer page on CSS padding: what it is, its effects and where it is useful.

**Category:** Learning Exercises  
**Tech:** HTML

## How to run

No build step or install needed. Open `Padding css/index.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "124_css-8"
python3 -m http.server 8000
```

then visit http://localhost:8000/Padding%20css/index.html.
