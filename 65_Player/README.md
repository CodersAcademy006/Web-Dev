# Music Player

Music player with play/pause, next/previous, progress bar, repeat/shuffle and a playlist.

**Category:** Tools & Apps  
**Tech:** HTML, CSS, JavaScript

## How to run

No build step or install needed. Open `Music Player in JavaScript/index.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "65_Player"
python3 -m http.server 8000
```

then visit http://localhost:8000/Music%20Player%20in%20JavaScript/index.html.
