# Frontend Bootcamp

Landing page for a web-development course ("Become a Web Developer") built with Bootstrap 5 and Bootstrap Icons.

**Category:** Websites & Landing Pages  
**Tech:** HTML, CSS, Bootstrap

## How to run

No build step or install needed. Open `index.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "22_COURSE_WEBSITE"
python3 -m http.server 8000
```

then visit http://localhost:8000/index.html.

## Files

```
index.html
style.css
```

Plus 3 asset files (images, audio, fonts, etc.).
