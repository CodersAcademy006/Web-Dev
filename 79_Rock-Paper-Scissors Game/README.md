# Rock Paper Scissors

Rock Paper Scissors against the computer with animated hands and a result message.

**Category:** Games  
**Tech:** HTML, JavaScript, CSS

## How to run

No build step or install needed. Open `Rock Paper Scissors/index.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "79_Rock-Paper-Scissors Game"
python3 -m http.server 8000
```

then visit http://localhost:8000/Rock%20Paper%20Scissors/index.html.
