# Othello

Two-player Othello (Reversi) with board and cell classes that flip captured discs.

**Category:** Games  
**Tech:** HTML, JavaScript

## How to run

No build step or install needed. Open `index.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "59_othello-board-game"
python3 -m http.server 8000
```

then visit http://localhost:8000/index.html.

## Files

```
index.html
scripts/board.js
scripts/cell.js
scripts/index.js
```

Plus 1 asset file (images, audio, fonts, etc.).
