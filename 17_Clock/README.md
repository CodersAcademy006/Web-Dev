# Alarm Clock

Digital clock with an alarm: pick hour, minute and AM/PM, and a ringtone plays when the time is reached.

**Category:** Tools & Apps  
**Tech:** HTML, JavaScript, CSS

## How to run

No build step or install needed. Open `index.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "17_Clock"
python3 -m http.server 8000
```

then visit http://localhost:8000/index.html.

## Files

```
index.html

style.css
```

Plus 2 asset files (images, audio, fonts, etc.).
