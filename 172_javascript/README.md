# JavaScript Exercises

JavaScript exercises: triangle checker, auto colour change, and a calculator with basic and scientific operations in `js-calculator/`.

**Category:** Learning Exercises  
**Tech:** JavaScript, HTML, CSS, Bootstrap, jQuery

## How to run

No build step or install needed. Open `traingle_checker.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "172_javascript"
python3 -m http.server 8000
```

then visit http://localhost:8000/traingle_checker.html.
