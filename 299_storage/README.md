# Random Number with localStorage

Generates a random number and remembers it in `localStorage` across reloads, with staggered reveal animations.

**Category:** Learning Exercises  
**Tech:** CSS, JavaScript, HTML

## How to run

No build step or install needed. Open `index.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "299_storage"
python3 -m http.server 8000
```

then visit http://localhost:8000/index.html.
