# Solartec 2022

Later copy of the Solartec site with images moved into `images/`. Open `Solartec Company.html`.

**Category:** Websites & Landing Pages  
**Tech:** CSS, HTML, Bootstrap, Font Awesome

## How to run

No build step or install needed. Open `Solartec Company.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "259_Solar2022"
python3 -m http.server 8000
```

then visit http://localhost:8000/Solartec%20Company.html.
