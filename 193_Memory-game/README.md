# Memory Game

Card-matching memory game. Original live demo: https://dimple-choudhary.github.io/Memory-game/

**Category:** Games  
**Tech:** HTML, JavaScript, CSS, Bootstrap

## How to run

No build step or install needed. Open `index.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "193_Memory-game"
python3 -m http.server 8000
```

then visit http://localhost:8000/index.html.

## Files

```
index.html
index.js
styles.css
```

Plus 10 asset files (images, audio, fonts, etc.).
