# CSS Tour: Font Family

Exercise on CSS `font-family`.

**Category:** Learning Exercises  
**Tech:** HTML, CSS

## How to run

No build step or install needed. Open `font-family/index.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "118_css-2"
python3 -m http.server 8000
```

then visit http://localhost:8000/font-family/index.html.
