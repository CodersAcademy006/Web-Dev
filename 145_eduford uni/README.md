# EduFord University

University website with home, about, courses, blog and contact pages.

**Category:** Websites & Landing Pages  
**Tech:** CSS, HTML, Font Awesome

## How to run

No build step or install needed. Open `html/about.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "145_eduford uni"
python3 -m http.server 8000
```

then visit http://localhost:8000/html/about.html.
