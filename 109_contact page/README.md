# Ristorante Con Fusion

"About us" page for the fictional Ristorante con Fusion, built with Bootstrap 4 (from the Coursera Bootstrap course).

**Category:** Websites & Landing Pages  
**Tech:** CSS, HTML, Bootstrap, jQuery, Font Awesome

## How to run

No build step or install needed. Open `index.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "109_contact page"
python3 -m http.server 8000
```

then visit http://localhost:8000/index.html.
