# Analog Clock

Analog clock with a dark/light mode toggle, driven by JavaScript.

**Category:** UI Components & CSS Effects  
**Tech:** HTML, JavaScript, CSS

## How to run

No build step or install needed. Open `Analog Clock/index.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "99_Watch"
python3 -m http.server 8000
```

then visit http://localhost:8000/Analog%20Clock/index.html.
