# Notes App

Sticky-notes app: add, edit and delete notes with title and description, saved in `localStorage`.

**Category:** Tools & Apps  
**Tech:** HTML, JavaScript, CSS, Unicons

## How to run

No build step or install needed. Open `Notes App in JavaScript/index.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "56_Note-App"
python3 -m http.server 8000
```

then visit http://localhost:8000/Notes%20App%20in%20JavaScript/index.html.
