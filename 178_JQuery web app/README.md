# ANN Mobile Page

Mobile page about artificial neural networks. Open `mobile.html`.

**Category:** Learning Exercises  
**Tech:** HTML

## How to run

No build step or install needed. Open `mobile.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "178_JQuery web app"
python3 -m http.server 8000
```

then visit http://localhost:8000/mobile.html.
