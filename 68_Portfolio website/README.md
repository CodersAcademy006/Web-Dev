# Portfolio Website (Karan Nath)

Personal portfolio with about, skills, projects and contact sections and a typing animation via Typed.js.

**Category:** Websites & Landing Pages  
**Tech:** HTML, JavaScript, CSS, Font Awesome, Typed.js

## How to run

No build step or install needed. Open `index.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "68_Portfolio website"
python3 -m http.server 8000
```

then visit http://localhost:8000/index.html.
