# Eyes That Follow

Cartoon eyes that follow the mouse. Open `eyes-that-follow.html`.

**Category:** UI Components & CSS Effects  
**Tech:** HTML

## How to run

No build step or install needed. Open `eyes-that-follow.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "173_javascript eyes"
python3 -m http.server 8000
```

then visit http://localhost:8000/eyes-that-follow.html.
