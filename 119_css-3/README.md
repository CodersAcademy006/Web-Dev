# CSS Tour: Margin & Border

Exercise on CSS margins and borders.

**Category:** Learning Exercises  
**Tech:** HTML, CSS

## How to run

No build step or install needed. Open `margin-border/index.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "119_css-3"
python3 -m http.server 8000
```

then visit http://localhost:8000/margin-border/index.html.
