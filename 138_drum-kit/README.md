# Drum Kit

Keyboard and click driven drum kit with sounds and button animations. Original live demo: https://biniltomjose1278.github.io/drum-kit/

**Category:** Games  
**Tech:** HTML, JavaScript, CSS

## How to run

No build step or install needed. Open `index.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "138_drum-kit"
python3 -m http.server 8000
```

then visit http://localhost:8000/index.html.

## Files

```
index.html
index.js
styles.css
```

Plus 14 asset files (images, audio, fonts, etc.).
