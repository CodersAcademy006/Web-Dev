# Login / Register Card

Flip card with a login form on one side and a registration form on the other.

**Category:** UI Components & CSS Effects  
**Tech:** HTML, CSS, Font Awesome

## How to run

No build step or install needed. Open `index.htm` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "14_card"
python3 -m http.server 8000
```

then visit http://localhost:8000/index.htm.
