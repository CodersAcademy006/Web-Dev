# HTML Basics

Collection of HTML exercises: headings, tables, forms, login and survey forms, video embedding, meta tags and a coin toss.

**Category:** Learning Exercises  
**Tech:** HTML, JavaScript, CSS, Font Awesome

## How to run

No build step or install needed. Open `Basic_form.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "171_html"
python3 -m http.server 8000
```

then visit http://localhost:8000/Basic_form.html.
