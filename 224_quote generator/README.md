# Quote Generator (jQuery)

Random quote machine with jQuery; quotes come from a GitHub gist and can be tweeted. By Yohannes Sida.

**Category:** API-Powered Apps  
**Tech:** HTML, JavaScript, CSS, Bootstrap, jQuery, Font Awesome

## How to run

No build step or install needed. Open `index.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "224_quote generator"
python3 -m http.server 8000
```

then visit http://localhost:8000/index.html.

## Files

```
index.html

styles.css
```

Plus 1 asset file (images, audio, fonts, etc.).
