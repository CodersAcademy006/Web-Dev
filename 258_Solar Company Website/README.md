# Solartec

Solar and renewable-energy company website with Bootstrap. Open `Solartec company.html`.

**Category:** Websites & Landing Pages  
**Tech:** CSS, HTML, Bootstrap, Font Awesome

## How to run

No build step or install needed. Open `Solartec company.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "258_Solar Company Website"
python3 -m http.server 8000
```

then visit http://localhost:8000/Solartec%20company.html.
