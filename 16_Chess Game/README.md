# Chess Game

Two-player chess on one screen with piece images and a turn indicator.

**Category:** Games  
**Tech:** CSS, JavaScript, HTML

## How to run

No build step or install needed. Open `CHESS/index.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "16_Chess Game"
python3 -m http.server 8000
```

then visit http://localhost:8000/CHESS/index.html.
