# NASA View Picker

Pick a NASA space image (nebula, galaxy clusters, star fields) and it becomes the background behind a cockpit window.

**Category:** Tools & Apps  
**Tech:** HTML, CSS, JavaScript

## How to run

No build step or install needed. Open `index.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "202_NASA Background Picker"
python3 -m http.server 8000
```

then visit http://localhost:8000/index.html.
