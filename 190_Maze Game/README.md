# Maze Game

Randomly generated maze with physics from Matter.js. Move the ball to the goal with W/A/S/D or the arrow keys.

**Category:** Games  
**Tech:** HTML, JavaScript, Matter.js

## How to run

No build step or install needed. Open `index.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "190_Maze Game"
python3 -m http.server 8000
```

then visit http://localhost:8000/index.html.
