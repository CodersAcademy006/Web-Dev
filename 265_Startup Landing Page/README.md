# Startup Landing Page

Startup landing template with ScrollReveal and anime.js animations. Sources in `src/`, built files in `dist/`.

**Category:** Websites & Landing Pages  
**Tech:** HTML, CSS, JavaScript, SCSS, anime.js, ScrollReveal

## How to run

No build step or install needed. Open `index.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "265_Startup Landing Page"
python3 -m http.server 8000
```

then visit http://localhost:8000/index.html.
