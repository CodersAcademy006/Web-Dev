# Flipping Credit Card

Credit card UI that flips on hover to show the back, built with CSS 3D transforms.

**Category:** UI Components & CSS Effects  
**Tech:** HTML, CSS

## How to run

No build step or install needed. Open `index.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "23_cradit-card animation"
python3 -m http.server 8000
```

then visit http://localhost:8000/index.html.

## Files

```
index.html
style.css
```

Plus 2 asset files (images, audio, fonts, etc.).
