# Palindrome Checker

Enter a word or phrase to check whether it is a palindrome.

**Category:** Tools & Apps  
**Tech:** HTML, JavaScript, CSS, jQuery

## How to run

No build step or install needed. Open `index.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "209_palindrome site"
python3 -m http.server 8000
```

then visit http://localhost:8000/index.html.
