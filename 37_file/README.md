# Drag & Drop File Upload

Drag-and-drop (or browse) image upload area that previews the selected image.

**Category:** UI Components & CSS Effects  
**Tech:** HTML, JavaScript, CSS, Font Awesome

## How to run

No build step or install needed. Open `Drag & Drop or Browse File/index.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "37_file"
python3 -m http.server 8000
```

then visit http://localhost:8000/Drag%20%26%20Drop%20or%20Browse%20File/index.html.
