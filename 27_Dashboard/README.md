# Admin Dashboard Panel

Responsive admin dashboard with a collapsible sidebar, dark-mode toggle, stat cards and an activity table.

**Category:** UI Components & CSS Effects  
**Tech:** HTML, JavaScript, CSS, Unicons

## How to run

No build step or install needed. Open `Admin Dashboard Panel/index.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "27_Dashboard"
python3 -m http.server 8000
```

then visit http://localhost:8000/Admin%20Dashboard%20Panel/index.html.
