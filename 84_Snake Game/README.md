# Snake Game

Classic Snake: eat food to grow, avoid walls and yourself. Keeps a high score and has on-screen controls for mobile.

**Category:** Games  
**Tech:** HTML, JavaScript, CSS, Font Awesome

## How to run

No build step or install needed. Open `Snake Game in JavaScript/index.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "84_Snake Game"
python3 -m http.server 8000
```

then visit http://localhost:8000/Snake%20Game%20in%20JavaScript/index.html.
