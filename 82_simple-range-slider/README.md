# Simple Range Slider

Horizontal and vertical range slider component written as a small reusable script.

**Category:** UI Components & CSS Effects  
**Tech:** HTML, JavaScript, CSS

## How to run

No build step or install needed. Open `index.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "82_simple-range-slider"
python3 -m http.server 8000
```

then visit http://localhost:8000/index.html.

## Files

```
index.html
scripts/index.js
scripts/simple-range-slider.js
styles/styles.css
```

Plus 1 asset file (images, audio, fonts, etc.).
