# Budget App

Enter a budget and add expenses; the app tracks the total spent and remaining balance.

**Category:** Tools & Apps  
**Tech:** HTML, JavaScript, CSS, Font Awesome

## How to run

No build step or install needed. Open `index.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "97_Budget App"
python3 -m http.server 8000
```

then visit http://localhost:8000/index.html.

## Files

```
index.html
style/script.js
style/styles.css
```

Plus 1 asset file (images, audio, fonts, etc.).
