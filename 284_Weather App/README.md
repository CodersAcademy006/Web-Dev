# Weather App

City weather search with the OpenWeatherMap API. Requires an API key in `script.js`.

**Category:** API-Powered Apps  
**Tech:** HTML, JavaScript, CSS

## How to run

No build step or install needed. Open `index.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "284_Weather App"
python3 -m http.server 8000
```

then visit http://localhost:8000/index.html.

> **API key needed:** this app calls the OpenWeatherMap API. Get a free key from OpenWeatherMap and put it in place of the key in the script before running.
