# Quiz App with Timer

Timed multiple-choice quiz with a countdown per question, answer feedback and a result screen.

**Category:** Games  
**Tech:** HTML, CSS, JavaScript, Font Awesome

## How to run

No build step or install needed. Open `Quiz Application with Timer/index.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "73_Quiz Website"
python3 -m http.server 8000
```

then visit http://localhost:8000/Quiz%20Application%20with%20Timer/index.html.
