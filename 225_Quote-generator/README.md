# Quote Generator

Random quotes from the type.fit API with a local fallback list and a tweet button.

**Category:** API-Powered Apps  
**Tech:** HTML, JavaScript, CSS, Font Awesome

## How to run

No build step or install needed. Open `Quote-generator/index.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "225_Quote-generator"
python3 -m http.server 8000
```

then visit http://localhost:8000/Quote-generator/index.html.
