# 404 Error Pages

Collection of three Tailwind CSS 404 page designs: a simple error, a 404 with footer and a centred 404. `index.html` links to each demo.

**Category:** UI Components & CSS Effects  
**Tech:** HTML, Tailwind CSS

## How to run

No build step or install needed. Open `index.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "3_404-error"
python3 -m http.server 8000
```

then visit http://localhost:8000/index.html.

## Files

```
1-simple-error.html
2-404-with-footer.html
3-404-center.html

```
