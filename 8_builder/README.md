# Resume Builder

Form-driven resume builder. Fill in your details and pick a theme (blue, grey, resume) to render a styled CV. Uses Bootstrap and jQuery.

**Category:** Tools & Apps  
**Tech:** CSS, JavaScript, HTML, Bootstrap, jQuery

## How to run

No build step or install needed. Open `index.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "8_builder"
python3 -m http.server 8000
```

then visit http://localhost:8000/index.html.
