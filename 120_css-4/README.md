# CSS Tour: Background Image

Exercise on CSS background images.

**Category:** Learning Exercises  
**Tech:** HTML, CSS

## How to run

No build step or install needed. Open `background-img/index.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "120_css-4"
python3 -m http.server 8000
```

then visit http://localhost:8000/background-img/index.html.

## Files

```
background-img/index.html
background-img/style.css
```

Plus 1 asset file (images, audio, fonts, etc.).
