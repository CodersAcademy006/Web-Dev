# Animated Clock

Animated analog clock. Open `watch.html`.

**Category:** UI Components & CSS Effects  
**Tech:** CSS, HTML

## How to run

No build step or install needed. Open `watch.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "308_Animated_Clock"
python3 -m http.server 8000
```

then visit http://localhost:8000/watch.html.
