# jsPDF with Custom Font

Demo of generating a PDF in the browser with jsPDF using an embedded custom font. Open `demo.html`.

**Category:** Tools & Apps  
**Tech:** HTML, jsPDF

## How to run

No build step or install needed. Open `demo.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "179_jsPDF with Custom font"
python3 -m http.server 8000
```

then visit http://localhost:8000/demo.html.
