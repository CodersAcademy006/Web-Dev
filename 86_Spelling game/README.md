# Spelling Bee

Spelling game: an image is shown and you type the word it represents.

**Category:** Games  
**Tech:** HTML

## How to run

No build step or install needed. Open `SpellingBee/index.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "86_Spelling game"
python3 -m http.server 8000
```

then visit http://localhost:8000/SpellingBee/index.html.
