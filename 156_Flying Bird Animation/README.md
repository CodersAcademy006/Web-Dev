# Flying Bird Animation

Birds flying across a sky using CSS sprite animation. Open `index.htm`.

**Category:** UI Components & CSS Effects  
**Tech:** HTML, CSS

## How to run

No build step or install needed. Open `index.htm` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "156_Flying Bird Animation"
python3 -m http.server 8000
```

then visit http://localhost:8000/index.htm.
