# CSS Tour: Text Decoration

Exercise on CSS text decoration.

**Category:** Learning Exercises  
**Tech:** HTML, CSS

## How to run

No build step or install needed. Open `text-decoration/index.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "121_css-5"
python3 -m http.server 8000
```

then visit http://localhost:8000/text-decoration/index.html.

## Files

```
text-decoration/index.html
text-decoration/style.css
```

Plus 1 asset file (images, audio, fonts, etc.).
