# Search Bar

Styled search bar. Open `search_bar.html`.

**Category:** UI Components & CSS Effects  
**Tech:** HTML

## How to run

No build step or install needed. Open `search_bar.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "245_Search Bar"
python3 -m http.server 8000
```

then visit http://localhost:8000/search_bar.html.
