# GO GREEN IT Company Template

Multi-page business website template for a software company: home, about, services, portfolio, pricing and contact pages.

**Category:** Websites & Landing Pages  
**Tech:** HTML, CSS, JavaScript, PHP, Bootstrap, jQuery

## How to run

No build step or install needed. Open `IT Company -Software Company Business Website/IT Company -Software Company Business Website/index.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "20_Company-Portfolio"
python3 -m http.server 8000
```

then visit http://localhost:8000/IT%20Company%20-Software%20Company%20Business%20Website/IT%20Company%20-Software%20Company%20Business%20Website/index.html.
