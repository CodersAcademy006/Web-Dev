# YouTube Clone

YouTube web UI clone styled with Tailwind CSS.

**Category:** Clones  
**Tech:** HTML, CSS, JavaScript, Tailwind CSS

## How to run

Open `index.html` in a browser (styles are prebuilt in `assets/style.css`).

To rebuild the Tailwind CSS: `npm install && npm run build:css`.

## Files

```
index.html
package.json
style.css
tailwind.config.js
assets/script.js
assets/style.css
assets/videos.json
```

Plus 5 asset files (images, audio, fonts, etc.).
