# Fluid Web Page

Fluid, responsive page about bungee jumping in Nepal. Open `Fluid-Webpage/index.html`.

**Category:** Websites & Landing Pages  
**Tech:** HTML, CSS

## How to run

No build step or install needed. Open `Fluid-Webpage/index.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "155_fluid-webpage"
python3 -m http.server 8000
```

then visit http://localhost:8000/Fluid-Webpage/index.html.
