# Drawing Pad

Freehand drawing pad on a canvas. Open `draw.html`.

**Category:** Tools & Apps  
**Tech:** CSS, HTML, JavaScript

## How to run

No build step or install needed. Open `draw.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "135_Drawing pad"
python3 -m http.server 8000
```

then visit http://localhost:8000/draw.html.
