# Email Client App

Small mobile-style app (App.js + Zepto) with screens to compose and "send" an email; the recipient is remembered in `localStorage`.

**Category:** Tools & Apps  
**Tech:** HTML, JavaScript, Zepto

## How to run

No build step or install needed. Open `index.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "146_Email-Client-App"
python3 -m http.server 8000
```

then visit http://localhost:8000/index.html.
