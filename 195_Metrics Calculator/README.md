# Convert Me

Engineering unit converter with pages for current, capacitance, length, resistance and temperature.

**Category:** Tools & Apps  
**Tech:** HTML, CSS, JavaScript, Bootstrap, Font Awesome, Animate.css

## How to run

No build step or install needed. Open `index.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "195_Metrics Calculator"
python3 -m http.server 8000
```

then visit http://localhost:8000/index.html.
