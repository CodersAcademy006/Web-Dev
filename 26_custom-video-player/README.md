# Custom Video Player

HTML5 video player with custom controls (play/pause, progress, volume) replacing the browser defaults.

**Category:** Tools & Apps  
**Tech:** HTML, JavaScript, CSS

## How to run

No build step or install needed. Open `index.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "26_custom-video-player"
python3 -m http.server 8000
```

then visit http://localhost:8000/index.html.

## Files

```
index.html
scripts/index.js
scripts/video.js
styles/styles.css
```

Plus 3 asset files (images, audio, fonts, etc.).
