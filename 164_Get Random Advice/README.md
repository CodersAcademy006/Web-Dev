# Get Random Advice

React app that fetches a random piece of advice from the Advice Slip API with axios.

**Category:** Framework & Full-Stack Apps  
**Tech:** HTML, CSS, JavaScript, axios, React

## How to run

```bash
npm install
npm start
```

Opens on http://localhost:3000.

public/index.html
