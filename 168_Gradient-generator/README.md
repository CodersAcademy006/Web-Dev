# Background Gradient Generator

Pick two colours to create a linear-gradient background and copy the CSS. Open `bggenerator.html`.

**Category:** Tools & Apps  
**Tech:** HTML, JavaScript, CSS

## How to run

No build step or install needed. Open `bggenerator.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "168_Gradient-generator"
python3 -m http.server 8000
```

then visit http://localhost:8000/bggenerator.html.
