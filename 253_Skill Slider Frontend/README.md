# Skill Slider

Scroll-driven image/section slider (SCSS source; compile `style.scss` to CSS first).

**Category:** UI Components & CSS Effects  
**Tech:** HTML, JavaScript, SCSS

## How to run

Compile the SCSS first, then open `index.html`:

```bash
npx sass style.scss style.css
```

```
index.html
script.js
```
