# Typing Speed Test

Timed typing test that reports your speed in words per minute. Original live demo: https://typing-speed-testbysudeep.netlify.app/

**Category:** Games  
**Tech:** HTML, CSS, JavaScript

## How to run

No build step or install needed. Open `typing_speed-test-webapp/index.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "302_Typing-Speed-test app"
python3 -m http.server 8000
```

then visit http://localhost:8000/typing_speed-test-webapp/index.html.
