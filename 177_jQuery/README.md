# jQuery Exercises

jQuery practice: email validation, event handling and selecting multiple targets, each in its own folder.

**Category:** Learning Exercises  
**Tech:** HTML, JavaScript, CSS, jQuery

## How to run

No build step or install needed. Open `dropdown-menu/index.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "177_jQuery"
python3 -m http.server 8000
```

then visit http://localhost:8000/dropdown-menu/index.html.
