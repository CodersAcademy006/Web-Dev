# Cricket

Three-page site about cricket (the game, champions, records) made before the ICC T20 World Cup 2022.

**Category:** Websites & Landing Pages  
**Tech:** HTML

## How to run

No build step or install needed. Open `index.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "114_cricket"
python3 -m http.server 8000
```

then visit http://localhost:8000/index.html.

## Files

```
Records.html
champs.html
index.html
```

Plus 3 asset files (images, audio, fonts, etc.).
