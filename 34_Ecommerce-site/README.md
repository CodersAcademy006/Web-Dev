# Thrift-Flip Store

Front-end of an e-commerce page for a clothing store (new arrivals, 2022 collection) built with W3.CSS and Font Awesome.

**Category:** Websites & Landing Pages  
**Tech:** HTML, Font Awesome, W3.CSS

## How to run

No build step or install needed. Open `e-com-page/index.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "34_Ecommerce-site"
python3 -m http.server 8000
```

then visit http://localhost:8000/e-com-page/index.html.
