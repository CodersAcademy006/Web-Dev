# Contact Us Form

Styled contact-us form. Open `login.html`.

**Category:** UI Components & CSS Effects  
**Tech:** CSS, HTML

## How to run

No build step or install needed. Open `login.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "110_Contact us form"
python3 -m http.server 8000
```

then visit http://localhost:8000/login.html.
