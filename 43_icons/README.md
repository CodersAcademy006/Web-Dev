# Social Icons

Row of social-media icon links with hover effects, using Font Awesome.

**Category:** UI Components & CSS Effects  
**Tech:** CSS, HTML, Font Awesome

## How to run

No build step or install needed. Open `mysocial.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "43_icons"
python3 -m http.server 8000
```

then visit http://localhost:8000/mysocial.html.
