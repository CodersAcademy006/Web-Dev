# Stopwatch

Stopwatch with start, stop and reset (CodingLab).

**Category:** Tools & Apps  
**Tech:** HTML, JavaScript, CSS

## How to run

No build step or install needed. Open `Stopwatch Application/index.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "298_Stop watch"
python3 -m http.server 8000
```

then visit http://localhost:8000/Stopwatch%20Application/index.html.
