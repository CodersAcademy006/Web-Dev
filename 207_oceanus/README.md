# Oceanus

Next.js site styled with Tailwind CSS, using Swiper carousels and React Icons.

**Category:** Framework & Full-Stack Apps  
**Tech:** JavaScript, CSS, Next.js, React, Swiper, Tailwind CSS

## How to run

```bash
npm install
npm run dev
```

Opens on http://localhost:3000. `npm run build && npm start` for a production build.
