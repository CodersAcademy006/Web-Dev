# Password Generator

Generate random secure passwords with one click.

**Category:** Tools & Apps  
**Tech:** HTML, JavaScript, CSS

## How to run

No build step or install needed. Open `password-generator/Password-Generator/index.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "63_Password Generator"
python3 -m http.server 8000
```

then visit http://localhost:8000/password-generator/Password-Generator/index.html.
