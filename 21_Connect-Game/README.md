# Connect Four

Two-player Connect Four. Drop red and yellow discs and the game detects four in a row.

**Category:** Games  
**Tech:** CSS, JavaScript, HTML

## How to run

No build step or install needed. Open `Connect4/index.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "21_Connect-Game"
python3 -m http.server 8000
```

then visit http://localhost:8000/Connect4/index.html.
