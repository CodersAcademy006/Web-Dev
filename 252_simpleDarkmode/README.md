# Simple Dark Mode

Bootstrap gallery page with a dark-mode toggle from darkmode.js. Open `ex.html`.

**Category:** UI Components & CSS Effects  
**Tech:** CSS, HTML, Bootstrap, darkmode.js

## How to run

No build step or install needed. Open `ex.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "252_simpleDarkmode"
python3 -m http.server 8000
```

then visit http://localhost:8000/ex.html.
