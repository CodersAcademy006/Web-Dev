# Dynamic Calendar

Month calendar that renders the current month and lets you step backwards and forwards between months, with today highlighted.

**Category:** UI Components & CSS Effects  
**Tech:** HTML, JavaScript, CSS

## How to run

No build step or install needed. Open `Dynamic Calendar JavaScript/index.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "9_Calander"
python3 -m http.server 8000
```

then visit http://localhost:8000/Dynamic%20Calendar%20JavaScript/index.html.
