# Rock Paper Scissors

Rock Paper Scissors with images against the computer. Open `rock_paper_scissiors.html`.

**Category:** Games  
**Tech:** HTML, JavaScript, CSS

## How to run

No build step or install needed. Open `rock_paper_scissiors.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "238_Rock Paper Scissors"
python3 -m http.server 8000
```

then visit http://localhost:8000/rock_paper_scissiors.html.
