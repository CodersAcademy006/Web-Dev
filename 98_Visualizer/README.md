# Sorting Visualizer

Animated sorting-algorithm visualiser with pages for bubble, insertion, selection, merge, quick and heap sort, highlighting swaps and comparisons.

**Category:** Tools & Apps  
**Tech:** HTML, CSS, SCSS, JavaScript

## How to run

No build step or install needed. Open `index.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "98_Visualizer"
python3 -m http.server 8000
```

then visit http://localhost:8000/index.html.
