# INFINITY vCard Template

vCard / resume / CV portfolio template with portfolio, resume and contact sections.

**Category:** Websites & Landing Pages  
**Tech:** HTML, CSS, JavaScript, jQuery, Font Awesome, Typed.js, Animate.css, Magnific Popup

## How to run

No build step or install needed. Open `index.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "218_Portfolio using HTML"
python3 -m http.server 8000
```

then visit http://localhost:8000/index.html.
