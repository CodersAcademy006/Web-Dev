# Restaurant Website

Food-ordering website with home, categories, category foods and an order form page.

**Category:** Websites & Landing Pages  
**Tech:** HTML, CSS

## How to run

No build step or install needed. Open `Resturant-web/index.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "78_Restaurant Website"
python3 -m http.server 8000
```

then visit http://localhost:8000/Resturant-web/index.html.
