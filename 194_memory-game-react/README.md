# Memory Game (React + TS)

Memory card game in React and TypeScript that loads character cards from the Rick and Morty GraphQL API via Apollo Client.

**Category:** Framework & Full-Stack Apps  
**Tech:** HTML, CSS, TypeScript, Apollo Client, GraphQL, React

## How to run

```bash
npm install
npm start
```

Opens on http://localhost:3000.
