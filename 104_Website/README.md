# Art Blog / Portfolio

Multi-page artist site: home, about, gallery, exhibitions, portfolio and blog pages under `public/`.

**Category:** Websites & Landing Pages  
**Tech:** HTML, CSS, JavaScript, Pug, SCSS, Bootstrap, Font Awesome, Swiper, Typed.js

## How to run

No build step or install needed. Open `public/index.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "104_Website"
python3 -m http.server 8000
```

then visit http://localhost:8000/public/index.html.
