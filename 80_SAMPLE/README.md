# Concert Project

Concert/event landing page with separate stylesheets for phone layouts.

**Category:** Websites & Landing Pages  
**Tech:** HTML, CSS

## How to run

No build step or install needed. Open `index.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "80_SAMPLE"
python3 -m http.server 8000
```

then visit http://localhost:8000/index.html.

## Files

```
index.html
main.css
phone.css
phone2.css
```

Plus 5 asset files (images, audio, fonts, etc.).
