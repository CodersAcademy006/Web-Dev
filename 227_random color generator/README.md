# Random Color Generator

Sets a random hex colour as the background, shows the code and lets you copy it.

**Category:** Tools & Apps  
**Tech:** HTML, JavaScript, CSS, Bootstrap, Font Awesome

## How to run

No build step or install needed. Open `index.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "227_random color generator"
python3 -m http.server 8000
```

then visit http://localhost:8000/index.html.
