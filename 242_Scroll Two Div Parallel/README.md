# Scroll Two Divs in Parallel

Two scrollable panes whose scroll positions stay in sync.

**Category:** UI Components & CSS Effects  
**Tech:** HTML

## How to run

No build step or install needed. Open `Scroll Two Div Parallel.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "242_Scroll Two Div Parallel"
python3 -m http.server 8000
```

then visit http://localhost:8000/Scroll%20Two%20Div%20Parallel.html.
