# File Downloader

Paste a file URL and download it directly from the browser using `fetch` and a Blob link.

**Category:** Tools & Apps  
**Tech:** HTML, JavaScript, CSS

## How to run

No build step or install needed. Open `File Downloader with JavaScript/index.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "29_Downloader"
python3 -m http.server 8000
```

then visit http://localhost:8000/File%20Downloader%20with%20JavaScript/index.html.
