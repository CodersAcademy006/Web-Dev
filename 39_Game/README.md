# Tic Tac Toe

Two-player Tic Tac Toe where X and O alternate turns.

**Category:** Games  
**Tech:** HTML, JavaScript, CSS, Font Awesome

## How to run

No build step or install needed. Open `Tic-TAc-Toe/index.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "39_Game"
python3 -m http.server 8000
```

then visit http://localhost:8000/Tic-TAc-Toe/index.html.
