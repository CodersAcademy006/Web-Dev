# Disk Scheduling Algorithms

Visualises disk scheduling algorithms (FCFS, SSTF, SCAN, C-SCAN) as head-movement charts with CanvasJS, with theory notes.

**Category:** Tools & Apps  
**Tech:** CSS, JavaScript, HTML, Bootstrap, jQuery, Swiper, CanvasJS

## How to run

No build step or install needed. Open `index.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "134_DiskSchedulingAlgorithms"
python3 -m http.server 8000
```

then visit http://localhost:8000/index.html.
