# Car Racing Game

Top-down car racing game. Steer with W/A/S/D to dodge oncoming cars on a scrolling road.

**Category:** Games  
**Tech:** HTML

## How to run

No build step or install needed. Open `CarGame/index.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "13_Car-Racing"
python3 -m http.server 8000
```

then visit http://localhost:8000/CarGame/index.html.
