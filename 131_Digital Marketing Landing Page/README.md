# Softy Pinko Landing Page

Digital-marketing landing page based on the Softy Pinko Bootstrap 4 theme from TemplateMo.

**Category:** Websites & Landing Pages  
**Tech:** HTML, CSS, JavaScript, Bootstrap, jQuery, Font Awesome, ScrollReveal

## How to run

No build step or install needed. Open `index.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "131_Digital Marketing Landing Page"
python3 -m http.server 8000
```

then visit http://localhost:8000/index.html.
