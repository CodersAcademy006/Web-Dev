# Linguistic Center

Website for a language institute. Course data is loaded from `lang.json` and a public JSON API. The Figma design is in `Design/`.

**Category:** Websites & Landing Pages  
**Tech:** HTML, CSS, SCSS, JavaScript, Bootstrap, Font Awesome

## How to run

No build step or install needed. Open `index.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "183_Linguistic Academy"
python3 -m http.server 8000
```

then visit http://localhost:8000/index.html.
