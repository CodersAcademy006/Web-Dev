# Password Generator

Single-file random password generator. Open `pass.html`.

**Category:** Tools & Apps  
**Tech:** HTML

## How to run

No build step or install needed. Open `pass.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "211_Password Generator"
python3 -m http.server 8000
```

then visit http://localhost:8000/pass.html.
