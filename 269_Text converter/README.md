# Text Converter (React)

React text utility app (uppercase, lowercase, clear, word count) in `newapp-master/`.

**Category:** Framework & Full-Stack Apps  
**Tech:** HTML, CSS, JavaScript, React, Bootstrap

## How to run

```bash
cd newapp-master
npm install
npm start
```

Opens on http://localhost:3000.
