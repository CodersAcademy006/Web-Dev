# Watch Store

Responsive watch e-commerce site with cart, featured products and Swiper sliders (Bedimcode design). Open `assets/index.html`.

**Category:** Websites & Landing Pages  
**Tech:** HTML, CSS, JavaScript, SCSS, Swiper, Boxicons

## How to run

No build step or install needed. Open `assets/index.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "283_watch-store"
python3 -m http.server 8000
```

then visit http://localhost:8000/assets/index.html.
