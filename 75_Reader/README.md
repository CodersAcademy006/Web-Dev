# QR Code Generator (Code Traversal)

Generate a QR code from text or a URL with `qrcode.js`.

**Category:** Tools & Apps  
**Tech:** HTML, JavaScript, CSS, qrcode.js

## How to run

No build step or install needed. Open `index.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "75_Reader"
python3 -m http.server 8000
```

then visit http://localhost:8000/index.html.
