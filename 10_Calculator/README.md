# Calculator

Basic calculator with a button grid for arithmetic, clear and delete.

**Category:** Tools & Apps  
**Tech:** HTML, JavaScript, CSS

## How to run

No build step or install needed. Open `Calculator/index.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "10_Calculator"
python3 -m http.server 8000
```

then visit http://localhost:8000/Calculator/index.html.
