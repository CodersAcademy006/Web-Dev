# Image Resizer

Upload an image, change its width and height (optionally locking the aspect ratio), reduce quality and download.

**Category:** Tools & Apps  
**Tech:** HTML, JavaScript, CSS

## How to run

No build step or install needed. Open `Image Resizer JavaScript/index.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "76_Resizer"
python3 -m http.server 8000
```

then visit http://localhost:8000/Image%20Resizer%20JavaScript/index.html.

## Files

```
Image Resizer JavaScript/index.html
Image Resizer JavaScript/script.js
Image Resizer JavaScript/style.css
```

Plus 2 asset files (images, audio, fonts, etc.).
