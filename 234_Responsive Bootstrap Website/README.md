# Responsive Bootstrap 5 Website

Four-page Bootstrap 5 site: home, about, gallery and contact.

**Category:** Websites & Landing Pages  
**Tech:** HTML, CSS, Bootstrap

## How to run

No build step or install needed. Open `index.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "234_Responsive Bootstrap Website"
python3 -m http.server 8000
```

then visit http://localhost:8000/index.html.

## Files

```
about.html
contact.html
gallery.html
index.html
style.css
```

Plus 6 asset files (images, audio, fonts, etc.).
