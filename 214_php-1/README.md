# Getting Started with PHP

Minimal "Hello World" PHP snippet embedded in HTML. Needs a PHP server to run.

**Category:** Learning Exercises  
**Tech:** HTML

## How to run

PHP code does not run inside a `.html` file. Rename `index.html` to `index.php`, then:

```bash
php -S localhost:8000
```

and open http://localhost:8000.
