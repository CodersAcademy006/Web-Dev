# Simple Quiz

Minimal quiz built from small helper modules that render questions and track the score.

**Category:** Games  
**Tech:** HTML, JavaScript, CSS

## How to run

No build step or install needed. Open `index.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "74_quiz-app"
python3 -m http.server 8000
```

then visit http://localhost:8000/index.html.

## Files

```
index.html
scripts/elements-helper.js
scripts/index.js
scripts/quiz.js
styles/styles.css
```

Plus 1 asset file (images, audio, fonts, etc.).
