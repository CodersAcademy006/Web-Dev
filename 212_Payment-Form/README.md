# Payment Form

Checkout form with contact and card payment fields. Open `payment_form.html`.

**Category:** UI Components & CSS Effects  
**Tech:** HTML, CSS

## How to run

No build step or install needed. Open `payment_form.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "212_Payment-Form"
python3 -m http.server 8000
```

then visit http://localhost:8000/payment_form.html.
