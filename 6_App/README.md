# Trading App UI

Dashboard UI for a trading app with Bootstrap layout and CanvasJS price charts driven by sample data.

**Category:** Websites & Landing Pages  
**Tech:** HTML, CSS, JavaScript, Bootstrap, jQuery, Font Awesome, CanvasJS

## How to run

No build step or install needed. Open `index.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "6_App"
python3 -m http.server 8000
```

then visit http://localhost:8000/index.html.

## Files

```
index.html
css/custom.css
js/custom.js
js/data-chart.js
```
