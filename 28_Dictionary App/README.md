# Dictionary App

Look up any English word to get its meaning, phonetics, example and synonyms, with pronunciation audio. Uses the Free Dictionary API.

**Category:** API-Powered Apps  
**Tech:** HTML, JavaScript, CSS, Font Awesome

## How to run

No build step or install needed. Open `Dictionary App in JavaScript/index.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "28_Dictionary App"
python3 -m http.server 8000
```

then visit http://localhost:8000/Dictionary%20App%20in%20JavaScript/index.html.
