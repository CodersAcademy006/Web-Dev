# CSS Tour: Pseudo-states

Exercise on CSS pseudo-classes such as `:hover` and `:active`.

**Category:** Learning Exercises  
**Tech:** HTML, CSS

## How to run

No build step or install needed. Open `pseduo-states/index.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "122_css-6"
python3 -m http.server 8000
```

then visit http://localhost:8000/pseduo-states/index.html.
