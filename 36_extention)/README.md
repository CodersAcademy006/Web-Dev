# Save Text As File

Type text, choose a file name and type (.txt, .js, .html, ...) and download it as a file.

**Category:** Tools & Apps  
**Tech:** HTML, JavaScript, CSS

## How to run

No build step or install needed. Open `Save Text As File JavaScript/index.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "36_extention)"
python3 -m http.server 8000
```

then visit http://localhost:8000/Save%20Text%20As%20File%20JavaScript/index.html.
