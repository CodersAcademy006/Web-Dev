# Random Quote Generator

Fetch a random quote from the Quotable API, with text-to-speech, copy and share-on-Twitter buttons.

**Category:** API-Powered Apps  
**Tech:** HTML, JavaScript, CSS, Font Awesome

## How to run

No build step or install needed. Open `Random Quote Generator in JavaScript/index.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "71_Qoute Generator"
python3 -m http.server 8000
```

then visit http://localhost:8000/Random%20Quote%20Generator%20in%20JavaScript/index.html.
