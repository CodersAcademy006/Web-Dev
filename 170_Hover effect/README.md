# Hover Effect

Hover effect written in Pug with CSS and JS (CodePen export). Compile `index.pug` to HTML to run it.

**Category:** UI Components & CSS Effects  
**Tech:** Pug, JavaScript, CSS

## How to run

`index.pug` must be compiled to HTML first:

```bash
npx pug-cli index.pug
```

Then open the generated `index.html`.

## Files

```
index.pug
script.js
style.css
```
