# VJS Jewelers

Jewellery shop website (Verma Ji & Sons) with home, about, gallery, services and contact pages.

**Category:** Websites & Landing Pages  
**Tech:** HTML, CSS, JavaScript, Bootstrap, jQuery, Font Awesome

## How to run

No build step or install needed. Open `index.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "174_Jewelery Blog website"
python3 -m http.server 8000
```

then visit http://localhost:8000/index.html.
