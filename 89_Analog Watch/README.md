# Analog Watch

Analog watch whose hands are rotated every second by JavaScript. Open `hp11.html`.

**Category:** UI Components & CSS Effects  
**Tech:** HTML, JavaScript

## How to run

No build step or install needed. Open `hp11.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "89_Analog Watch"
python3 -m http.server 8000
```

then visit http://localhost:8000/hp11.html.
