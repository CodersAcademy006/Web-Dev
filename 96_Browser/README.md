# PyQt5 Web Browser

Minimal desktop web browser written in Python with PyQt5 and QtWebEngine: back, forward, reload, home and a URL bar.

**Category:** Python Scripts  
**Tech:** Python

## How to run

```bash
pip install PyQt5 PyQtWebEngine
python Browser.py
```

Opens a maximised window on google.com.
