# GERICHT Restaurant

React landing page for a fine-dining restaurant (menu, chef, awards, gallery) built with Create React App and React Bootstrap.

**Category:** Framework & Full-Stack Apps  
**Tech:** HTML, CSS, JavaScript, Bootstrap, React, React Bootstrap

## How to run

```bash
npm install
npm start
```

Opens on http://localhost:3000.
