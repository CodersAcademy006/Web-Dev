# Online Mock Test System

Single-file timed mock-test/quiz with questions, a timer and a solutions view.

**Category:** Games  
**Tech:** HTML

## How to run

No build step or install needed. Open `index.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "208_OnlineMockTestSystem"
python3 -m http.server 8000
```

then visit http://localhost:8000/index.html.
