# Dynamic Todo List

Todo list with add, edit, delete and filtering (all / pending / completed).

**Category:** Tools & Apps  
**Tech:** HTML, CSS, JavaScript, Unicons

## How to run

No build step or install needed. Open `Todo List App/index.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "50_list app"
python3 -m http.server 8000
```

then visit http://localhost:8000/Todo%20List%20App/index.html.
