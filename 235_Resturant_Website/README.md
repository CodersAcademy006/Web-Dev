# Restaurant Website (React)

Restaurant website in React (Create React App) with React Icons, deployable to GitHub Pages via `npm run deploy`.

**Category:** Framework & Full-Stack Apps  
**Tech:** HTML, CSS, JavaScript, React

## How to run

```bash
npm install
npm start
```

Opens on http://localhost:3000.

`npm run deploy` builds and publishes to GitHub Pages (`gh-pages`).
