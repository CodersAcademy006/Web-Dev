# Snakes and Ladders

Snakes and Ladders board game with dice rolls in the browser.

**Category:** Games  
**Tech:** CSS, JavaScript, HTML

## How to run

No build step or install needed. Open `SnakesAndLadder/index.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "47_Ladder"
python3 -m http.server 8000
```

then visit http://localhost:8000/SnakesAndLadder/index.html.
