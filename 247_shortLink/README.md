# Short Links

URL shortener using the Rebrandly API via jQuery. Requires a Rebrandly API key in `js/app.js`.

**Category:** API-Powered Apps  
**Tech:** HTML, CSS, JavaScript, jQuery

## How to run

No build step or install needed. Open `index.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "247_shortLink"
python3 -m http.server 8000
```

then visit http://localhost:8000/index.html.

> **API key needed:** this app calls the Rebrandly API. Get a free key from Rebrandly and put it in place of the key in the script before running.
