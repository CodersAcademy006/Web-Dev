# Zacson Gym Template

Multi-page gym and fitness trainer template: home, about, courses, pricing, blog and contact (the contact form posts to a PHP handler).

**Category:** Websites & Landing Pages  
**Tech:** HTML, PHP, CSS, JavaScript, SCSS, Bootstrap, jQuery, Font Awesome, Animate.css, Unicons, Magnific Popup

## How to run

No build step or install needed. Open `zacson-master/index.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "38_Fitness Website"
python3 -m http.server 8000
```

then visit http://localhost:8000/zacson-master/index.html.

> The contact form posts to `contact_process.php`, which needs a PHP server with mail configured (`php -S localhost:8000`).
