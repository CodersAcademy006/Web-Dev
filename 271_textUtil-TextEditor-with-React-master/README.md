# TextUtils (React)

React text editor with case conversion, word/character count and dark mode.

**Category:** Framework & Full-Stack Apps  
**Tech:** HTML, CSS, JavaScript, React, Bootstrap

## How to run

```bash
npm install
npm start
```

Opens on http://localhost:3000.
