# Intro to Open Source Event

Event page for an "Introduction to Open Source" session with speakers and date, animated with AOS.

**Category:** Websites & Landing Pages  
**Tech:** CSS, HTML, AOS

## How to run

No build step or install needed. Open `event.html` in a browser.

Or serve the folder locally (recommended for pages that call an API or load local files):

```bash
cd "147_Event"
python3 -m http.server 8000
```

then visit http://localhost:8000/event.html.

## Files

```
event.css
event.html
```

Plus 2 asset files (images, audio, fonts, etc.).
