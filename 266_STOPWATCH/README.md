# Stopwatch (React)

Stopwatch in React (Create React App) with start, stop and reset.

**Category:** Framework & Full-Stack Apps  
**Tech:** HTML, CSS, JavaScript, SCSS, React

## How to run

```bash
npm install
npm start
```

Opens on http://localhost:3000.
